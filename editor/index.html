사용법
1. 원하는 계이름 줄(왼쪽 표시)에서, 원하는 타이밍(칸)을 클릭하면 노란 점이 찍히고 소리가 나요. 다시 클릭하면 지워져요.
2. 음 길이: Q=0.5박, W=1박, E=2박 (또는 위쪽 버튼 클릭).
3. Shift+클릭은 ///(트레몰로), A+클릭은 A(반음 UP), S+클릭은 S(한 키 UP) 표시로 찍혀요.
   키보드 대신 위쪽 '반음 UP' · '한 키 UP' · '트레몰로 추가' 버튼을 눌러서 모드를 켠 채로 계속 클릭해도 돼요 (다시 누르면 꺼짐).
4. 이 표시들은 실제 게임에서 다가오는 점 위에 그대로 나타나서, 연주자에게 "이 음은 반음/한 키 올려 치세요" 또는 "트레몰로로 치세요"라고 안내해줘요.
5. Ctrl+클릭으로 여러 음을 선택할 수 있고(다시 Ctrl+클릭하면 해제), Ctrl+A로 전체 선택, 선택된 상태에서 Delete/Backspace로 한 번에 지울 수 있어요. Esc는 선택 해제예요.
6. Ctrl+Z 되돌리기, Ctrl+Y 다시 실행.
7. 왼쪽 계이름 글자를 클릭하면 그 음을 바로 들어볼 수 있어요.
8. '재생' 버튼으로 지금까지 만든 곡을 처음부터 들어볼 수 있고(빨간 선이 재생 위치), '테스트 플레이'로 실제 게임처럼 플레이해볼 수 있어요.
9. 다 만들었으면 '코드 내보내기'를 누르고, 아래 상자에 나온 내용을 통째로 복사해서
   게임 파일(index.html)의 const SONG = [ ... ]; 부분을 통째로 바꿔치기 하면 새 곡으로 바로 플레이할 수 있어요.
