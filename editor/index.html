사용법
1. 원하는 계이름 줄(왼쪽 표시)에서, 원하는 타이밍(칸)을 클릭하면 노란 점이 찍히고 소리가 나요. 다시 클릭하면 지워져요.
2. 음 길이: Q=0.25박, W=0.5박, E=0.75박, R=1박, T=1.25박, Y=1.5박, U=1.75박, I=2박 (또는 위쪽 버튼 클릭).
3. Shift+클릭은 ///(트레몰로), A+클릭은 A(반음 UP), S+클릭은 S2(반음 UP+2, B·F#현 전용), D+클릭은 D(한 키 UP) 표시로 찍혀요. Shift+A+클릭처럼 동시에 누르면 반음/한 키 UP과 트레몰로를 함께 적용할 수 있어요(A///, S2///, D///).
   키보드 대신 위쪽 '반음 UP' · '반음 UP+2' · '한 키 UP' · '트레몰로 추가' 버튼을 눌러서 모드를 켠 채로 계속 클릭해도 돼요 (버튼은 서로 독립적이라 같이 켤 수 있어요). 반음 UP+2는 B·F#현이 아니면 자동으로 일반 반음으로 대체돼요.
4. 이 표시들은 실제 게임에서 다가오는 점 위에 그대로 나타나고, 표시된 조작(반음/한 키 올려 치기, 트레몰로)을 하지 않으면 MISS 판정이 나요.
5. Ctrl+클릭으로 여러 음을 선택할 수 있고(다시 Ctrl+클릭하면 해제), Ctrl+A로 전체 선택, 선택된 상태에서 Delete/Backspace로 한 번에 지울 수 있어요. Esc는 선택 해제예요.
   한 음을 클릭한 뒤 다른 음을 Shift+클릭하면, 그 사이 타이밍 범위에 있는 모든 계이름의 음이 한 번에 선택돼요.
   선택된 음 위에서 그대로 마우스를 누른 채 끌면, 선택된 음들이 함께 원하는 위치(계이름·타이밍)로 이동해요.
6. Ctrl+Z 되돌리기, Ctrl+Y 다시 실행.
7. 왼쪽 계이름 글자를 클릭하면 그 음을 바로 들어볼 수 있어요.
8. '재생' 버튼(또는 스페이스바)으로 지금까지 만든 곡을 들어볼 수 있고(빨간 선이 재생 위치), '테스트 플레이'로 실제 게임처럼 플레이해볼 수 있어요. 다시 누르면 일시정지예요.
   그리드 맨 위의 작은 눈금 줄을 클릭하면 그 위치가 재생 시작점으로 표시되고, 거기서부터 재생할 수 있어요.
9. 새 곡을 다 만들었으면 '✅ 편집 완료'를 눌러서 곡 이름 등을 입력하면, 코드 복사 없이 바로 곡 목록에 등록돼요.
   직접 코드가 필요하면 '코드 내보내기'로 아래 상자에 코드를 받아 게임 파일의 const SONG = [ ... ]; 부분에 붙여넣어도 돼요.
