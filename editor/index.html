사용법
1. 원하는 계이름 줄(왼쪽 표시)에서, 원하는 타이밍(칸)을 클릭하면 노란 점이 찍히고 소리가 나요. 다시 클릭하면 지워져요.
2. 위쪽에서 '0.5박' · '1박' · '2박' 중 음 길이를 고른 뒤 클릭하면, 그 길이만큼 늘여 치는 음을 찍을 수 있어요.
3. Shift를 누른 채로 클릭하면 점 대신 /// 기호가 찍혀요 (슬라이드 노트 표시용). 다시 클릭하면 지워져요.
4. '재생' 버튼으로 지금까지 만든 곡을 처음부터 들어볼 수 있어요 (빨간 선이 재생 위치예요).
5. 다 만들었으면 '코드 내보내기'를 누르고, 아래 상자에 나온 내용을 통째로 복사해서
   게임 파일(nabiya-game.html)의 const SONG = [ ... ]; 부분을 통째로 바꿔치기 하면 새 곡으로 바로 플레이할 수 있어요.
